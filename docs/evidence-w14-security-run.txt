== AUTHENTICATION ==
No token on /api/reports -> 401 UNAUTHENTICATED
Wrong password -> 401 INVALID_CREDENTIALS
Unknown user -> 401 INVALID_CREDENTIALS   (identical response: no user enumeration)
Valid student login -> token issued (3 parts, HS256)

== ALTERED / EXPIRED / INVALID TOKENS ==
Altered payload (role->custodian), original signature -> 401 UNAUTHENTICATED
Signed with attacker secret -> 401 UNAUTHENTICATED
alg:none unsigned token -> 401 UNAUTHENTICATED
Correctly signed but expired token -> 401 UNAUTHENTICATED

Student sending X-Role: custodian header -> 403 FORBIDDEN
Custodian -> GET /api/manual-queue -> 200
Other student reading R-0001 (owned by stu1) -> 404 NOT_FOUND   (404, not 403: ids cannot be probed)
